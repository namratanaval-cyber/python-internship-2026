# Responsive Internship Board

A beginner-friendly responsive internship listing website built as part of the EdVyro Full Stack Development internship.

## Project Overview

The Responsive Internship Board helps users find internship opportunities using a search box and domain filter. The interface is designed to work on desktop, tablet, and mobile devices.

## Features

* Responsive design for mobile, tablet, and desktop
* Internship search functionality
* Domain-based filtering
* Internship cards with company, domain, and location
* Empty-state message when no internship is found
* Keyboard-friendly form controls
* Semantic HTML structure

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Internship Domains

* Web Development
* Data Science
* Java
* Python

## Project Files

* `index.html` – Main webpage structure
* `style.css` – Responsive styling and layout
* `script.js` – Internship data, search, and filtering functionality

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Use the search box and domain filter to explore internships.
